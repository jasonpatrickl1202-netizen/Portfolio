## Portfolio

A modern and interactive personal portfolio website built to showcase my
background, technical skills, certifications, projects, and interests in
networking and technology.

## About

This portfolio represents my learning journey as an Undergraduate Computer
Science student with a strong interest in computer networking and IT
infrastructure.

The website is designed to present my technical interests, certifications,
future projects, and continuous learning journey in a clean and modern
interface.

## Features

- Modern and responsive portfolio design
- Floating navigation bar
- Smooth scrolling navigation
- Dark / Light mode
- Animated section transitions
- Scroll reveal animations
- Interactive cursor effects
- Interactive project card tilt effect
- Certification image carousel
- Certification library
- Project library
- Project detail modal
- Short project video previews
- Animated Tools & Technologies marquee
- Hover-to-pause skill animation
- Clickable technology logos
- Responsive layout for desktop, tablet, and mobile

## Sections

### Home

A personal introduction with a profile section and a short overview.

### About

Contains:

- Personal introduction
- Skills and interests
- Tools & Technologies
- Professional direction

### Certifications

A collection of certifications with:

- Certification images
- Certification details
- Issuer
- Date
- Additional information

More certifications can be added through the certification library.

### Projects

A collection of current and future projects.

Each project can contain:

- Preview image
- Short video
- Project description
- Technologies used
- Interactive project details

Additional projects can be added to the project library.

### Contact

Contains links and contact information for connecting with me.

## Technologies

This website is built using:

- HTML5
- CSS3
- JavaScript
- Google Fonts

### Design

The interface uses:

- Playfair Display
- Inter
- Responsive CSS Grid and Flexbox
- CSS animations
- CSS transitions
- Glassmorphism-inspired components

## Tools & Technologies

The portfolio currently highlights technologies and tools related to my
interests, including:

- MikroTik
- Cisco
- CapCut
- Adobe Photoshop
- Visual Studio Code

The technology cards use an animated horizontal marquee. The animation
automatically pauses when the user hovers over a specific technology card,
allowing the user to interact with it comfortably.
